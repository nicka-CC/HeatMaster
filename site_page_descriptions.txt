Это подробное описание страниц веб-приложения "HeatMaster" на основе анализа файлов проекта.

==============================
Страница: Главная (Home)
URL: /
==============================
Описание:
Это центральная страница сайта, служащая основной точкой входа для всех посетителей. Она представляет собой витрину, на которой отображаются ключевые категории продукции, такие как различные типы терморегуляторов. Кроме того, на странице размещены ссылки на справочные материалы по важным товарным группам, например, нагревательным матам и кабелям. Основная цель страницы — быстро познакомить пользователя с ассортиментом компании и предоставить удобную навигацию по основным разделам. Для привлечения внимания используется динамический слайдер с изображениями популярных товаров или акций.

==============================
Страница: Каталог термостатов (Thermostat List)
URL: /thermostats/ и /thermostats/type/<int:type_id>/
==============================
Описание:
На этой странице отображается полный список термостатов, доступных для покупки. Страница обладает богатой функциональностью для удобного поиска и фильтрации товаров. Пользователи могут фильтровать список по типу, производителю, стране производства, а также устанавливать диапазон цен. Для удобства навигации по большому количеству товаров реализована пагинация. Также присутствует поисковая строка для быстрого поиска по названию, модели или производителю. Эта страница является ключевой для процесса выбора и покупки товаров.

==============================
Страница: Детали термостата (Thermostat Detail)
URL: /thermostat/<int:pk>/
==============================
Описание:
Это страница конкретного товара, на которой представлена вся подробная информация о выбранном термостате. Здесь пользователь может увидеть изображения товара, его технические характеристики, цену, наличие на складе и подробное описание. Важной частью страницы является секция с комментариями и отзывами других покупателей, что помогает принять решение о покупке. Авторизованные пользователи могут оставить свой собственный комментарий и поставить оценку товару. Отсюда же пользователь может добавить товар в корзину для последующего оформления заказа.

==============================
Страница: Корзина (Cart)
URL: /cart/
==============================
Описание:
Страница корзины доступна только авторизованным пользователям и отображает все товары, которые были добавлены для покупки. Пользователь может просматривать список товаров, изменять количество каждого из них, а также видеть итоговую стоимость заказа. На этой странице также можно отметить необходимость услуги установки, что повлияет на конечную цену. Из корзины пользователь может либо продолжить покупки, либо перейти к оформлению заказа. Также есть возможность удалить товары из корзины.

==============================
Страница: Оформление заказа (Checkout)
URL: /checkout/
==============================
Описание:
Это финальный шаг в процессе покупки, доступный после перехода из корзины. На этой странице пользователь вводит необходимую для доставки информацию, такую как адрес и контактные данные. Здесь же можно оставить комментарий к заказу для менеджера. После подтверждения заказа все товары из корзины формируются в новый заказ в системе, их количество списывается со склада, а корзина пользователя очищается. Успешное оформление заказа перенаправляет пользователя на страницу с подтверждением.

==============================
Страница: Мои заказы (My Orders)
URL: /my-orders/
==============================
Описание:
На этой странице авторизованный пользователь может просмотреть историю всех своих прошлых и текущих заказов. Заказы отображаются в виде списка с указанием номера, даты, статуса и итоговой суммы. Эта страница служит личным кабинетом клиента для отслеживания своих покупок. Для удобства просмотра большого списка заказов реализована пагинация. Это помогает пользователю контролировать свои расходы и статус доставки.

==============================
Страница: Все заказы (All Orders) - для менеджеров
URL: /all-orders/
==============================
Описание:
Эта страница доступна только пользователям из группы "Manager" и предназначена для управления всеми заказами в системе. Менеджер видит полный список заказов от всех пользователей, отсортированный по дате. На странице реализована возможность фильтрации заказов по их статусу (например, "Новый", "Оплачен", "Отправлен"). Менеджер может перейти на страницу редактирования конкретного заказа, чтобы изменить его статус или другие детали. Эта страница является важным инструментом для операционной деятельности компании.

==============================
Страница: Управление пользователями (User Management) - для менеджеров
URL: /manage/users/
==============================
Описание:
Специализированная страница, доступная исключительно менеджерам для управления учетными записями клиентов. На ней в виде таблицы представлен список всех пользователей, за исключением суперпользователей и других менеджеров. Менеджер может просматривать основную информацию о пользователях: имя, фамилию, email и статус активности. Для каждого пользователя доступны действия "Редактировать" и "Удалить", позволяющие изменять их данные или блокировать доступ к сайту. Эта страница централизует управление клиентской базой.

==============================
Страница: Регистрация (Sign Up)
URL: /signUp/
==============================
Описание:
Страница регистрации позволяет новым посетителям создать учетную запись на сайте. Пользователю предлагается заполнить форму, указав логин, email, имя, фамилию и пароль с подтверждением. Система проверяет корректность введенных данных, например, совпадение паролей и уникальность логина. После успешной регистрации пользователь автоматически входит в систему и перенаправляется на главную страницу. Это первый шаг для получения доступа к персонализированным функциям, таким как корзина и история заказов.

==============================
Страница: Вход (Sign In)
URL: /signIn/
==============================
Описание:
Эта страница предназначена для аутентификации уже зарегистрированных пользователей. Пользователю необходимо ввести свой логин и пароль для входа в систему. В случае успешной аутентификации пользователь получает доступ к своему личному кабинету, корзине и истории заказов. Если данные введены неверно, на странице отобразится сообщение об ошибке. Эта страница является стандартным шлюзом для доступа к защищенным разделам сайта.

==============================
Страница: Блог (Blog)
URL: /blog/
==============================
Описание:
На этой странице представлен список всех статей, опубликованных в блоге компании. Статьи служат для информирования клиентов о новостях, технологиях, советах по выбору и установке продукции. Каждая статья в списке имеет заголовок и главное изображение для привлечения внимания. Пользователи могут выбрать интересующую их статью и перейти на страницу с ее полным текстом. Блог является важным инструментом контент-маркетинга для повышения лояльности клиентов и привлечения трафика.

==============================
Страница: Детали статьи блога (Blog Detail)
URL: /blog/<int:blog_id>/
==============================
Описание:
Здесь отображается полный текст выбранной статьи блога. Кроме основного контента, на странице также присутствует форма для добавления комментариев. Зарегистрированные пользователи могут оставлять свои отзывы, задавать вопросы и ставить статье оценку. Под статьей выводится список всех существующих комментариев, отсортированных по дате. Эта страница способствует вовлечению пользователей и созданию сообщества вокруг бренда.

==============================
Страницы: Информационные/Продуктовые
URL: /about/, /videos/, /heated-mats/, /contacts/, /delivery-payment/, /cooperation/, /manufacturers/, /thermoregulator/, и другие.
==============================
Описание:
Это группа страниц со статической или полу-статической информацией, каждая из которых выполняет свою функцию. Страница "О нас" рассказывает историю и миссию компании. "Видео" содержит обучающие или рекламные видеоролики. "Контакты" предоставляет контактные данные и форму обратной связи. "Доставка и оплата" и "Сотрудничество" описывают соответствующие условия работы. "Производители" знакомит с брендами, продукция которых представлена в магазине. Каждая из этих страниц направлена на информирование пользователя по конкретному вопросу.
