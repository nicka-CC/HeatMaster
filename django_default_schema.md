# Описание стандартных таблиц Django

Этот документ описывает структуру и назначение стандартных таблиц, создаваемых фреймворком Django для аутентификации, администрирования и управления сессиями.

---

## Таблица: `auth_user`

**Описание:** Основная таблица для хранения информации о пользователях системы.

| Поле | Тип данных | Описание | Ключ / Ограничения |
|---|---|---|---|
| `id` | `INTEGER` | Уникальный идентификатор пользователя. | **Первичный ключ (Primary Key)** |
| `password` | `VARCHAR(128)` | Хэшированный пароль пользователя. | |
| `last_login` | `DATETIME` | Дата и время последнего входа в систему. | Может быть `NULL`. |
| `is_superuser` | `BOOLEAN` | Флаг, указывающий, имеет ли пользователь все права без их явного назначения. | |
| `username` | `VARCHAR(150)` | Уникальное имя пользователя. | **Уникальное (UNIQUE)** |
| `first_name` | `VARCHAR(150)` | Имя пользователя. | |
| `last_name` | `VARCHAR(150)` | Фамилия пользователя. | |
| `email` | `VARCHAR(254)` | Адрес электронной почты. | |
| `is_staff` | `BOOLEAN` | Флаг, указывающий, может ли пользователь входить в панель администратора. | |
| `is_active` | `BOOLEAN` | Флаг, указывающий, активна ли учетная запись. Неактивные пользователи не могут войти. | |
| `date_joined` | `DATETIME` | Дата и время регистрации пользователя. | |

---

## Таблица: `auth_group`

**Описание:** Хранит группы пользователей. Группы используются для удобного назначения набора прав нескольким пользователям.

| Поле | Тип данных | Описание | Ключ / Ограничения |
|---|---|---|---|
| `id` | `INTEGER` | Уникальный идентификатор группы. | **Первичный ключ (Primary Key)** |
| `name` | `VARCHAR(150)` | Уникальное название группы. | **Уникальное (UNIQUE)** |

---

## Таблица: `auth_permission`

**Описание:** Хранит все доступные в системе права доступа (например, "может добавлять пользователя", "может изменять статью"). Права обычно создаются автоматически для каждой модели.

| Поле | Тип данных | Описание | Ключ / Ограничения |
|---|---|---|---|
| `id` | `INTEGER` | Уникальный идентификатор права. | **Первичный ключ (Primary Key)** |
| `content_type_id` | `INTEGER` | Ссылка на модель, к которой относится право. | **Внешний ключ (Foreign Key)** к `django_content_type.id`. |
| `codename` | `VARCHAR(100)` | Кодовое название права (например, `add_user`). | |
| `name` | `VARCHAR(255)` | Человекочитаемое название права. | |
| - | - | - | **Уникальное ограничение (Unique Constraint)** на (`content_type_id`, `codename`). |

---

## Таблица: `django_content_type`

**Описание:** Отслеживает все модели, установленные в проекте, создавая связь между приложениями и их моделями. Используется для обобщенных связей.

| Поле | Тип данных | Описание | Ключ / Ограничения |
|---|---|---|---|
| `id` | `INTEGER` | Уникальный идентификатор. | **Первичный ключ (Primary Key)** |
| `app_label` | `VARCHAR(100)` | Название приложения, которому принадлежит модель. | |
| `model` | `VARCHAR(100)` | Название модели в нижнем регистре. | |
| - | - | - | **Уникальное ограничение (Unique Constraint)** на (`app_label`, `model`). |

---

## Промежуточные таблицы (для связей "Многие-ко-многим")

### Таблица: `auth_user_groups`
*   **Описание:** Связывает пользователей с группами.
*   `id`: Первичный ключ.
*   `user_id`: **Внешний ключ** к `auth_user.id`.
*   `group_id`: **Внешний ключ** к `auth_group.id`.

### Таблица: `auth_group_permissions`
*   **Описание:** Связывает группы с правами доступа.
*   `id`: Первичный ключ.
*   `group_id`: **Внешний ключ** к `auth_group.id`.
*   `permission_id`: **Внешний ключ** к `auth_permission.id`.

### Таблица: `auth_user_user_permissions`
*   **Описание:** Назначает индивидуальные права доступа напрямую пользователям.
*   `id`: Первичный ключ.
*   `user_id`: **Внешний ключ** к `auth_user.id`.
*   `permission_id`: **Внешний ключ** к `auth_permission.id`.

## Системные и служебные таблицы

## Таблица: `django_admin_log`

**Описание:** Журнал действий, которые пользователи совершают в панели администратора Django (добавление, изменение, удаление объектов).

| Поле | Тип данных | Описание | Ключ / Ограничения |
|---|---|---|---|
| `id` | `INTEGER` | Уникальный идентификатор записи. | **Первичный ключ (Primary Key)** |
| `action_time` | `DATETIME` | Время совершения действия. | |
| `user_id` | `INTEGER` | Пользователь, совершивший действие. | **Внешний ключ (Foreign Key)** к `auth_user.id`. |
| `content_type_id` | `INTEGER` | Тип объекта, над которым совершено действие. | **Внешний ключ (Foreign Key)** к `django_content_type.id`. |
| `object_id` | `TEXT` | ID объекта, над которым совершено действие. | |
| `object_repr` | `VARCHAR(200)`| Текстовое представление объекта. | |
| `action_flag` | `SMALLINT` | Тип действия (1: добавление, 2: изменение, 3: удаление). | |
| `change_message` | `TEXT` | Сообщение, описывающее изменения. | |

---

## Таблица: `django_session`

**Описание:** Хранит данные сессий. Django использует эту таблицу для отслеживания сеансов пользователей между запросами.

| Поле | Тип данных | Описание | Ключ / Ограничения |
|---|---|---|---|
| `session_key` | `VARCHAR(40)` | Уникальный идентификатор сессии. | **Первичный ключ (Primary Key)** |
| `session_data` | `TEXT` | Закодированные данные сессии. | |
| `expire_date` | `DATETIME` | Дата и время истечения срока действия сессии. | |

---

## Таблица: `django_migrations`

**Описание:** Отслеживает, какие миграции базы данных уже были применены. Это позволяет Django понимать, какие изменения схемы нужно внести при запуске команды `migrate`.

| Поле | Тип данных | Описание | Ключ / Ограничения |
|---|---|---|---|
| `id` | `INTEGER` | Уникальный идентификатор записи. | **Первичный ключ (Primary Key)** |
| `app` | `VARCHAR(255)` | Название приложения, к которому относится миграция. | |
| `name` | `VARCHAR(255)` | Название файла миграции. | |
| `applied` | `DATETIME` | Дата и время применения миграции. | |
