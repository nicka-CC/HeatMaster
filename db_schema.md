# Описание схемы базы данных "HeatMaster"

Этот документ описывает структуру таблиц базы данных, сгенерированную на основе `models.py` Django-проекта.

---

## Таблица: `Thermostats`

**Описание:** Хранит основные категории или типы термостатов.

| Поле | Тип данных | Описание | Ключ / Ограничения |
|---|---|---|---|
| `id` | `INTEGER` | Уникальный идентификатор записи. | **Первичный ключ (Primary Key)** |
| `type` | `VARCHAR(120)` | Название типа термостата (например, "Программируемый", "Wi-Fi"). | |
| `icon` | `VARCHAR(100)` | Путь к файлу с иконкой для данного типа. | Может быть пустым. |

| `price` | `FLOAT` | Цена товара. | |
